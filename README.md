## 🌟 Visão Geral

A **Pousada Angel** combina conforto e hospitalidade com uma apresentação digital envolvente. O site tem como principal objetivo apresentar a infraestrutura da pousada, detalhar os tipos de acomodações, exibir depoimentos de hóspedes e direcionar o cliente para o fluxo de reservas diretas.

---

## 🚀 Funcionalidades e Seções

- 🎥 **Hero Section com Vídeo de Fundo:** Apresentação imersiva com vídeo em *loop*, chamada para ação (CTA) em destaque e estatísticas de satisfação dos hóspedes.
- 📖 **Sobre a Pousada:** Seção institucional contando a história de mais de 10 anos de tradição da pousada.
- 🛏️ **Catálogo de Acomodações:** Apresentação detalhada dos quartos com tamanho, comodidades (Wi-Fi, Ar-condicionado, TV Smart, Frigobar, etc.) e distintivos como *"Popular"*, *"Família"* e *"Amigos"*.
- ⭐ **Depoimentos & Avaliações:** Integração visual de reviews verificados de plataformas como *TripAdvisor*, *Google* e *Booking*.
- ☕ **Lista de Comodidades:** Destaque dos diferenciais oferecidos (Recepção 24h, Piscina ao ar livre, Café da manhã incluso, Estacionamento gratuito).
- 🗺️ **Localização e Contato:** Informações claras de endereço e canais diretos de comunicação.
- 📅 **Sistema/Modal de Reserva Directa:** Botão de ação rápida (*"RESERVAR AGORA"*) visível no topo e no menu de navegação.

## ♿ Diferenciais de UX/UI e Acessibilidade

- **Acessibilidade Native (ARIA):** Utilização de rótulos semânticos (`aria-label`, `aria-hidden`) para leitores de tela e navegação por teclado.
- **Navegação Responsiva & Mobile Menu:** Menu adaptável para telas menores com suporte a toque.
- **Otimização de Mídia:** Imagens com suporte a *lazy loading* para maior velocidade de carregamento.
- **Design Semântico:** Estruturação correta com tags HTML5 (`<header>`, `<main>`, `<section>`, `<article>`, `<nav>`, `<footer>`).

## 💻 Como Executar o Projeto Localmente

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/seu-usuario/pousada-angel.git
   ```

2. **Acesse a pasta do projeto:**
   ```bash
   cd pousada-angel
   ```

3. **Abra o arquivo `index.html`:**
   - Dobre o clique no arquivo `index.html` **ou**
   - Utilize a extensão **Live Server** no VS Code para rodar um servidor local em `http://127.0.0.1:5500/`.
